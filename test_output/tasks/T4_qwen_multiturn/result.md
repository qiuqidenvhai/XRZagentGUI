TCP 三次握手，通俗来说就像两个人打电话前互相确认“能听到对方”：
第一次握手（客户端 → 服务端）：
A 拨通电话问：“喂，你能听到我说话吗？”（发送 SYN 请求包）
第二次握手（服务端 → 客户端）：
B 听到了，回答：“我能听到你！你能听到我吗？”（回复 SYN+ACK 确认包）
第三次握手（客户端 → 服务端）：
A 说：“能听到！那咱们开聊吧！”（发送 ACK 确认包）
为什么必须是三次？
因为只有通过这三次交流，A 和 B 才能互相确认“我的发送正常、你的接收正常、你的发送正常、我的接收正常”。双方都确认了彼此的收发能力没问题后，连接才正式建立，开始传输数据。

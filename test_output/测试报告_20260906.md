## 问题诊断

### 问题1: 队列堵塞
**原因**: `/interrupt` API只中断当前任务，不清除等待队列。

**影响**: 新任务被放在队列末尾，必须等前面所有任务完成才能执行。

**解决方案**: 
- 方案A: 发送新消息前自动清空队列
- 方案B: 添加`/clear_queue` API端点
- 方案C: `/interrupt`增加参数`clear_queue=true`

### 问题2: pendingAttachments=0
**这是正常行为**，不是bug。

**原因**: 文件上传后立即被处理（添加到FILE_LIST），pendingAttachments在发送消息后被清空。

**验证**:
```python
pending = await page.evaluate("() => window.pendingAttachments ? window.pendingAttachments.length : 0")
# 返回0是正常的，因为文件已被上传到FILE_LIST
```
